# Security Policy

The Agneax OS development team takes the security and integrity of our operating system seriously. We appreciate the responsible disclosure of any potential vulnerabilities.

---

## Supported Versions

Only the latest official release receives active security patches:

| Release Version | Supported |
| :--- | :--- |
| `v0.1.0` | :white_check_mark: Supported |
| `< v0.1.0` | :x: Not Supported |

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security flaw, vulnerability, or exposure in Agneax OS:

1. **Email Us**: Send a detailed report directly to `security@agneax.org`.
2. **Include Details**:
   - Operating system version and architecture.
   - Detailed description of the vulnerability.
   - Proof-of-concept code or step-by-step instructions to reproduce the issue.
   - Potential impact or attack vectors.
3. **Response Timeline**:
   - Our team will acknowledge receipt of your report within **48 hours**.
   - We will provide a status update and estimated resolution timeframe within **7 business days**.
   - Once a fix is verified and ready, a security update will be published via **System Updater** and reflected in release notes.

We ask that you maintain mutual confidentiality until an official patch has been published to protect our user community.
