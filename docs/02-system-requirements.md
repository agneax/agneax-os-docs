# 02. System Requirements

Ensure your hardware meets the following specifications before installing Agneax OS.

[SCREENSHOT: System Specifications page inside Agneax System Settings]

## Minimum Hardware Requirements

These specifications allow Agneax OS to boot and operate standard desktop workflows:

- **CPU**: 64-bit dual-core processor (x86_64 architecture, 2.0 GHz or higher)
- **RAM**: 2 GB system memory
- **Storage**: 20 GB available drive space (HDD or SSD)
- **Graphics**: Display adapter capable of 1024 x 768 screen resolution with basic OpenGL acceleration
- **Network**: Wired Ethernet or supported Wi-Fi adapter (recommended for initial setup and updates)
- **Input**: Standard USB keyboard and mouse or touchpad

## Recommended Hardware Specifications

These specifications provide optimal system responsiveness, fast application switching, and fluid multimedia playback:

- **CPU**: Modern 64-bit quad-core processor (Intel Core i3/i5/i7, AMD Ryzen, or equivalent)
- **RAM**: 4 GB or 8 GB system memory
- **Storage**: 64 GB or higher Solid State Drive (SATA SSD or NVMe)
- **Graphics**: Intel HD/UHD Graphics, AMD Radeon, or NVIDIA graphics card with 3D hardware acceleration
- **Display**: 1920 x 1080 (Full HD) or higher resolution screen
- **Network**: Broadband Internet connectivity

## Firmware & Compatibility

- **Boot Support**: Both standard Legacy BIOS and modern UEFI (64-bit) boot modes are supported.
- **Secure Boot**: For the initial installation, disabling Secure Boot in your motherboard BIOS/UEFI settings is recommended.
- **Virtual Machines**: Agneax OS runs seamlessly inside VirtualBox, VMware Workstation, and QEMU/KVM. Enable 3D acceleration and allocate at least 2 CPU cores and 4 GB RAM for testing.
