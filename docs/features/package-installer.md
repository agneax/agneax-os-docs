# Feature: Package Installer

The **Agneax Package Installer** allows users to easily install software packages downloaded from the web.

[SCREENSHOT: Package Installer reviewing package information, version, and dependencies]

## Highlights

- **One-Click Installation**: Double-click downloaded package files directly from the file manager.
- **Dependency Resolution**: Automatically checks and resolves required system libraries before applying installations.
- **Package Inspection**: View package name, author, version, description, and list of installed files before proceeding.
- **Safe Removal**: Uninstall third-party applications cleanly without leaving orphaned configuration files behind.
